# Mahdis Sabzi — portfolio website

Live site: https://kariminima2005-glitch.github.io/mahdis-portfolio/

Plain HTML, CSS and JavaScript (no build step), hosted on GitHub Pages.

| File / folder | What it is | Content from |
|---|---|---|
| `index.html` | Home: her portrait drawn in coloured ASCII characters — scrolling zooms into her eye — then a forward 3D flight past all 114 project images (each resolves from characters into the photo as you approach, click to open). Then the project index with hover films, the full film with chapters, and About (portrait, contact, education, skills) | Original portfolio `PT 18.pptx` slides 1–3 and 29; films from the earlier V5 work |
| `in-between.html`, `rasta.html`, `children-hospital.html`, `iran-pavilion.html` | One page per project: concept, project film, design process, drawings, perspectives, renders/model, more views | Text copied word for word from `PT 18.pptx`; images listed below |
| `img/orig/` | Original drawings, diagrams, sketches and the clean original renders (no watermark) | `PT 18.pptx` media |
| `img/ai/` | Clean, same-angle visualisations that replace every Gendo-watermarked render, plus extra views | `images.zip` / earlier V5 work (`renders/graded`) |
| `img/extra/` | Twinmotion renders of the Revit model, model views, extra elevations and site plan, portrait | `renders/`, `1.residential.zip`, `2.sport club.zip`, `3.children hospital.zip`, supplied portrait photo |
| `img/film/`, `media/` | Film posters and the six silent films (1280 px H.264) | Earlier V5 work |
| `portfolio.pdf` | Download copy of the 44-page portfolio (screen quality) | Built from the recoloured `PT 18.pptx` |
| `assets/style.css`, `assets/main.js` | Styling (palette backgrounds, Syne + Instrument Sans) and interactions (reveals, film player, lightbox, transitions) | — |

The print-quality PDF and the editable PowerPoint are in `Documents\Mahdis\pdf`.
